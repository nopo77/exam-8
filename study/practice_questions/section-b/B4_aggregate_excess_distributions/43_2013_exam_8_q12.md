# 2013 Exam 8 - Q12

**Points:** 2.5

## Question

Given the following loss ratios for a set of five identical risks:

| Risk | Loss Ratio |
| --- | --- |
| 1 | 40% |
| 2 | 40% |
| 3 | 80% |
| 4 | 100% |
| 5 | 140% |

Assume that the sample loss ratio of 80% equals the expected loss ratio.

Construct a Table M showing the insurance charges for entry ratios from 0 to 2.0 in increments of 0.50.

| 1.25 | 1.50 | 1 | 0.2 | 0.05 |

|  | 2.00 | 0 | 0 | 0 |
