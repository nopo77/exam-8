# 2004 Exam 9 - Q43

**Points:** 2

## Question

Given the following sample of loss experience from a collection of five similarly sized risks:

| Risk | Annual Loss |
| --- | --- |
| 1 | $2,100,000 |
| 2 | $1,400,000 |
| 3 | $800,000 |
| 4 | X |
| 5 | Y |
| AVERAGE | $1,000,000 |

Calculate the insurance savings ψ(0.8) . Show all work.

## Solution

**X+Y:** $700,000 — `=C12*5-SUM(C7:C9)`

X and Y will be the only losses below $800,000 (since we know collectively they add to $700,000). From here, we can take several approaches.

r

2.1 — `=C7/C$12` — Approach 1: Calculate the charge at r=0.8 using vertical slices, then use that to get the savings

1.4 — `=C8/C$12`

0.8 — `=C9/C$12` — Charge at r=0.8 — 0.38 — `=(G7-0.8)*(1/5)+(G8-0.8)*(1/5)`

**Savings at r=0.8:** 0.18 — `=J9+0.8-1`

Approach 2: Calculate the savings directly using vertical slices

Savings in dollars = (1/5)(800,000-X)+(1/5)(800,000-Y) = 800,000*(2/5)-(1/5)*(X+Y) = 800,000*(2/5)-(1/5)* 700,000

**Loss at r=0.8:** $800,000 — `=0.8*C12`

**Savings in dollars:** 180,000 — `=J17*(2/5)-J2*(1/5)`

**Psi(0.8):** 0.18 — `=J19/C12`

Approach 3: Build a Table M

Entry ratios for X and Y must each be below 0.8 since (X+Y) / 1M = 0.7
