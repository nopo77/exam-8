# 2008 Exam 9 - Q28

**Points:** 3

## Question

Five identical retrospectively rated workers compensation policies have the following actual loss ratio experience:

| Policy Number | Loss Ratio |
| --- | --- |
| 1 | 100% |
| 2 | 20% |
| 3 | 160% |
| 4 | 80% |
| 5 | 40% |
| Average | 80% |

### Part a (1.00 pts)

Two basic methods for constructing a Table M from a set of empirical data are the Horizontal Slices method and the Vertical Slices method. Discuss the relative advantages and disadvantages of these methods.

### Part b (2.00 pts)

Using the empirical data above, construct a Table M that exhibits the insurance charge for the entry ratios from 0.00 to 2.00, in increments of 0.25.

## Solution

### Part a

Advantages of using vertical slices:

More intuitive since it corresponds to the way the data is presented. Quicker if just need charge for 1 entry ratio.

Disadvantages of vertical slices:

Not efficient for calculating charges at multiple entry ratios.

Advantages of using horizontal slices:

More efficient when calculating charges at multiple entry ratios. Tables M and L use this approach

Disadvantages of using horizontal slices:

Not intuitive Time consuming if charge only needed for 1 entry ratio
