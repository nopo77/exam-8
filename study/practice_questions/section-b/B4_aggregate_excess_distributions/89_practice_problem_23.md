# Practice Problem 23

**Points:** 1.75

## Question

Given the following losses for a set of identical risks:

| Policy # | Claim # | Loss Amount |
| --- | --- | --- |
| 1 | 1 | $30,000 |
| 1 | 2 | $5,000 |
| 2 | 3 | $45,000 |
| 3 | 4 | $60,000 |
| 3 | 5 | $100,000 |
| 4 | 6 | $80,000 |
| 5 | 7 | $250,000 |

Construct a  Table L using this data and a — $50,000 — loss limit and calculate the charge for

each entry ratio present in the data.

## Solution

0.25 points for calculating the correct entry ratios for each policy (divide by E[A]) 0.25 points for having the charge at max entry ratio equal to k 0.25 points for using the correct formula for the charge 0.75 points for calculating the correct charge values (deduct 0.25 for each mistake)
