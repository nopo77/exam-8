# Practice Problem 22

**Points:** 1.75

## Question

Given the following losses for a set of identical risks:

| Policy # | Claim # | Loss Amount |
| --- | --- | --- |
| 1 | 1 | $30,000 |
| 1 | 2 | $5,000 |
| 2 | 3 | $45,000 |
| 3 | 4 | $60,000 |
| 3 | 5 | $100,000 |
| 4 | 6 | $80,000 |
| 5 | 7 | $250,000 |

Construct a Table M using this data and calculate the charge for each entry ratio present in the data.
