# 2005 Exam 9 - Q8

**Points:** 2.5

## Question

Given the following aggregate loss ratios used to calculate insurance charges based on Table M procedures:

| Risk | Aggregate Loss Ratios |
| --- | --- |
| 1 | 20% |
| 2 | 40% |
| 3 | 60% |
| 4 | 64% |
| 5 | 72% |
| 6 | 80% |
| 7 | 80% |
| 8 | 96% |
| 9 | 128% |
| 10 | 160% |

Assume:

| B | C |
| --- | --- |
| $1,250 | Standard premium for each risk |
| 80% | Expected loss ratio |

### Part a (2.00 pts)

Calculate the insurance charge φ(1.1).

### Part b (0.50 pts)

Calculate the insurance savings ψ(1.1).

## Solution
