# 2017 Exam 8 - Q8

**Points:** 1.75

## Question

An insurer sells the following coverage:

| B | C |
| --- | --- |
| 5,000 | Attachment point |
| 5,000 | Layer limit |

The following table represents the expected cumulative severity distribution and limited expected severity for the current year at various limits:

| k | F(k) | E[X;k] |
| --- | --- | --- |
| 4,545 | 0.842 | 1,807 |
| 5,000 | 0.859 | 1,875 |
| 5,500 | 0.875 | 1,941 |
| 9,091 | 0.938 | 2,256 |
| 10,000 | 0.947 | 2,308 |
| 11,000 | 0.954 | 2,357 |

10% — Expected severity increase for all claim sizes next year

### Part a (0.75 pts)

Calculate the percent change in frequency of claims in the layer.

### Part b (1.00 pts)

Calculate the percent change in pure premiums in the layer.

## Solution

### Part a

Note that by frequency of claims in the layer, we are really asking about how many claims hit the layer, not about claims with sizes exactly in the size interval. That said, the graders decided that "claims in the layer" was ambiguous, so they awarded points for interpreting this as claims exactly in the size interval.

Solution 1 (the intended solution): All claims that contribute to the layer

**a/tau:** 4,545.45 — `=B6/(1+B20)`

**Tau_N:** 1.12 — `=(1-D13)/(1-D14)`

**% change in freq in layer:** 12.1% — `=D37-1`

Solution 2 (not recommended): All claims in the size interval

| limit l | F(l) |
| --- | --- |
| 4,545.45 | 0.842 |
| 5,000 | 0.859 |
| 9,090.91 | 0.938 |
| 10,000 | 0.947 |

### Part b

Solution 1 (intended based on all claims that contribute to the layer): using Tau_S

**(a+l)/tau:** 9,090.91 — `=(B6+B7)/(1+B20)`

**Tau_S:** 1.14 — `=(1+$B$20)*(E16-E13)/(E17-E14)`

**% change in pp in layer:** 14.1% — `=D58-1`

Solution 2 (intended based on all claims that contribute to the layer): multiplying freq change by severity change
