# 2006 Exam 9 - Q6

**Points:** 2

## Question

Given the following table of increased limit factors:

| Limit of Insurance | Increased Limit Factor |
| --- | --- |
| 25,000 | 1.00 |
| 50,000 | 1.60 |
| 100,000 | 2.60 |
| 250,000 | 6.60 |
| 500,000 | 10.00 |

Change one increased limit factor so that all of the factors in the table pass the consistency test.

## Solution

To pass the consistency test:

[I(250k) - 2.6)] / (250k-100k) <= 0.00002 — [10 - I(250k)] / (500k - 250k) <= [I(250k) - 2.6)] / (250k-100k)

| B | C | E | F |
| --- | --- | --- | --- |
| I(250k) <= | 5.6 | 250,000 | 150,000 |
|  |  | 650,000 | 1,500,000 |

<details><summary>Formulas</summary>

- `C19` = `=J9*(B10-B9)+C9`
- `E19` = `=B11-B10`
- `F19` = `=B10-B9`
- `E20` = `=C9*E19`
- `F20` = `=C11*F19`

</details>

**I(250k) >=:** 5.375 — `=(E20+F20)/(E19+F19)`

Any value between 5.375 and 5.6 would suffice.
