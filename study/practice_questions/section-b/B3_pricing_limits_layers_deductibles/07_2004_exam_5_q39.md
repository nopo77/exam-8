# 2004 Exam 5 - Q39 revised

**Points:** 3

## Question

Given the information below, calculate the premium for a policy with a $5,000 straight deductible. Show all work.

Claim Size Distribution

| Probability | Claim Size (Loss only) |
| --- | --- |
| 0.45 | $500 |
| 0.35 | $2,500 |
| 0.15 | $10,000 |
| 0.05 | $25,000 |

| B | C |
| --- | --- |
| $5,000 | Deductible on policy |
| $500,000 | First dollar premium |
| 60% | Ground-up expected loss ratio |
| 10% | Allocated Loss Adjustment Expenses (as a percentage of loss) |
| $95,000 | Fixed expense |
| 12% | Variable expense |
| 3% | Profit and contingency provision |

- Assume the deductible applies to loss and ALAE.

## Solution

Note that the deductible applies to loss and ALAE, so we need to add ALAE to loss when calculating the Loss Elimination Ratio. The formulas as shown in the lessons assumed the deductible applied to loss only. "First dollar" premium means the premium with no deductible.

| Loss&ALAE | cap at d |
| --- | --- |
| $550 | $550 |
| $2,750 | $2,750 |
| $11,000 | $5,000 |
| $27,500 | $5,000 |

**LER (incl ALAE):** 0.522 — `=SUMPRODUCT(J9:J12,B9:B12)/SUMPRODUCT(I9:I12,B9:B12)`

**XS Ratio (incl ALAE):** 0.478 — `=1-L15`

**Expected GU Loss&ALAE:** $330,000 — `=B15*B16*(1+B17)`
