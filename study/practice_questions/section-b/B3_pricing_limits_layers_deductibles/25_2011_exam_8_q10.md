# 2011 Exam 8 - Q10

**Points:** 3.5

## Question

Consider the following set of consistent increased limits factors (ILFs):

| Per Occurrence Limit | ILF |
| --- | --- |
| $100,000 | 1.000 |
| $250,000 | 1.250 |
| $500,000 | 1.450 |
| $1,000,000 | 1.750 |
| $2,000,000 | 2.250 |

### Part a (2.50 pts)

Assume an ILF for a limit of $750,000 is to be added to the table above.

Determine the range of possible ILFs for a limit of $750,000 that would maintain the consistency of the above set of ILFs.

### Part b (1.00 pts)

Explain how the consistency test has both a mathematical interpretation and a practical meaning.

| Per Occurrence Limit | ILF |
| --- | --- |
| $100,000 | 1.000 |
| $250,000 | 1.250 |
| $500,000 | 1.450 |
| $750,000 | x |
| $1,000,000 | 1.750 |
| $2,000,000 | 2.250 |

## Solution

### Part a

I'(l)

0.0000017 — `=(L4-L3)/(K4-K3)`

0.0000008 — `=(L5-L4)/(K5-K4)`

**x <=:** 1.65 — `=N5*(K6-K5)+L5`

0.0000005 — `=(L8-L7)/(K8-K7)` — x <= — 1.625 — `=L7-N8*(K7-K6)`

| K | L |
| --- | --- |
| $250,000 | $437,500 |
| $250,000 | $362,500 |

<details><summary>Formulas</summary>

- `K10` = `=K6-K5`
- `L10` = `=K10*L7`
- `K11` = `=K7-K6`
- `L11` = `=K11*L5`

</details>

**x >=:** 1.6 — `=(L11+L10)/(K11+K10)`

So 1.6 <= x <= 1.625

### Part b

The mathematical interpretation is that I'(l) >= 0 and I''(l) <= 0.

The practical interpretation is that as the limit increases, there are less losses expected at higher layers, so rates should not increase more for higher limits than for lower limits.
