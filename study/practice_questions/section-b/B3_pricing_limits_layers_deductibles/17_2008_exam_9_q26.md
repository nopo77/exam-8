# 2008 Exam 9 - Q26

**Points:** 2

## Question

A particular segment of policies is priced using the following increased limits factors (ILFs):

| Limit ($) | ILF |
| --- | --- |
| 100,000 | 0.950 |
| 110,000 | 1.000 |
| 121,000 | 1.050 |
| 200,000 | 1.400 |
| 220,000 | 1.475 |
| 242,000 | 1.550 |
| 400,000 | 2.000 |
| 440,000 | 2.100 |
| 484,000 | 2.200 |

The following additional information is also applicable to these policies:

| B | C |
| --- | --- |
| $35,000 | The expected average per-claim severity at a limit of $110,000 |
| 0.25 | The expected average loss frequency (claims per policy term) |
| 10.0% | The expected annual inflation rate for loss severity |

### Part a (1.00 pts)

Calculate the increased limit factor adjusted for one year of inflation for a policy limit of $440,000.

### Part b (1.00 pts)

Calculate the pure premium charge adjusted for one year of inflation for a policy covering losses in the layer $110,000 excess of $110,000.
