# 2010 Exam 9 - Q17

**Points:** 2

## Question

Use the following table of increased limit factors to answer the questions below:

| Limit | ILF |
| --- | --- |
| $50,000 | 0.85 |
| $100,000 | 1.00 |
| $250,000 | 1.21 |
| $500,000 | 1.33 |
| $1,000,000 | 1.64 |

### Part a (1.00 pts)

Demonstrate which of these ILFs violates the consistency test.

### Part b (1.00 pts)

Determine a range of values that would allow this ILF table to pass the consistency test.

## Solution

### Part a

I'(l)

0.00000300 — `=(D8-D7)/(C8-C7)`

0.00000140 — `=(D9-D8)/(C9-C8)`

0.00000048 — `=(D10-D9)/(C10-C9)`

0.00000062 — `=(D11-D10)/(C11-C10)` — Test fails at $1M since I''(l)>0

### Part b

x >= 1.33

(x - 1.33)/(1M - 500k) <= 0.00000048

1.33 <= I(1M) <= 1.57

Optional I''(l) rescaled

-1.07 — `=(K9-K8)/(C9-C8)*100000000000`

-0.37 — `=(K10-K9)/(C10-C9)*100000000000`

0.03 — `=(K11-K10)/(C11-C10)*100000000000`

**x <=:** 1.57 — `=K10*(C11-C10)+D10`
