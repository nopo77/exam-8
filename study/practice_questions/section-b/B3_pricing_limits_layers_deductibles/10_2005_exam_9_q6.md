# 2005 Exam 9 - Q6

**Points:** 2

## Question

Given the following table of increased limit factors:

| Policy Limit | Increased Limit Factor |
| --- | --- |
| $95,238 | 0.956 |
| $100,000 | 1.000 |
| $105,000 | 1.045 |
| $476,190 | 1.600 |
| $500,000 | 1.632 |
| $525,000 | 1.660 |
| $1,904,762 | 2.172 |
| $2,000,000 | 2.205 |
| $2,100,000 | 2.235 |
| $2,380,952 | 2.304 |
| $2,500,000 | 2.325 |
| $2,625,000 | 2.333 |

Assume:

| B | C |
| --- | --- |
| 5% | Annual inflation rate |
| 0.20 | Average loss frequency |
| $16,000 | Expected severity at the $100,000 limit |

### Part a (0.50 pts)

Calculate the increased limit factor adjusted for one year of inflation for a policy limit of $500,000.

### Part b (1.50 pts)

Calculate the pure premium charge adjusted for one year of inflation for a policy covering losses in the layer $2,000,000 excess of $500,000.
