# Practice Problem 2

## Question

Suppose for a set of risks, you observe the following average correlations between each risk's losses for different separations in time t:

| t | Correlation |
| --- | --- |
| 1 | 0.725 |
| 2 | 0.438 |
| 3 | 0.213 |
| 4 | 0.005 |
| 5 | -0.104 |
| 6 | -0.004 |
| 7 | 0.045 |

What would you conclude about your ability to estimate future losses for these risks?

## Solution

Since the correlations drop off over time, risk parameters are shifting over time, and more recent years should get more weight (credibility) in estimating future losses.
