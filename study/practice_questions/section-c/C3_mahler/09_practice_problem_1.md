# Practice Problem 1

## Question

Mahler notes 3 simplifications found in baseball data that are not found in insurance data. What are they?

## Solution

A constant set of risks The baseball loss data is readily available, accurate, and not subject to development. Each team is of equal size; they each play roughly the same # of games each year.
