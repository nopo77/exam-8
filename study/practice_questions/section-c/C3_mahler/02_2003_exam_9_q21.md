# 2003 Exam 9 - Q21

**Points:** 1

## Question

Briefly describe two methods to test whether risk parameters shift over time.

## Solution

Method 1: Chi-Squared Test

Perform the following for each risk (team) separately:

Group data (e.g., claim counts) into n equally-sized time intervals (e.g., 5 year intervals). For each interval, calculate chi-squared = (A-E)^2 / E; where A = actual observation for interval, E = expected observation for interval Sum up chi-squared across all n intervals. Compare the total chi-squared value against a chi-squared table value for the appropriate degrees of freedom (n-1) and confidence level. If total chi-squared value > table value, then conclude actual and expected distributions are different, and risk parameters have shifted over time. If total chi-squared value < table value, then conclude actual and expected distributions are the same, and risk parameters have not shifted over time.

Method 2: Correlation Test

Compute the correlation between observations for all risks for every possible pair of years during the historical period (e.g., claim frequency across all risks for 1950 with claim frequency for the same risks in 1951, 1952, etc. Then again calculate correlation between 1951 and 1952, 1953, etc.). For a given separation in time t, calculate the average of the correlations. If the average correlation decreases as time lag increases, then risk parameters shift over time.
