# 2014 Exam 8 - Q8

**Points:** 2.5

## Question

An actuary is pricing a one-year commercial general liability occurrence policy. The following information is available:

- Renewal effective date is January 1, 2014
- Losses are evaluated as of September 1, 2013

| Effective Date of Policy | Company Subject Loss Costs |
| --- | --- |
| 2013-01-01 | $35,700 |
| 2012-01-01 | 50,300 |
| 2011-01-01 | 40,300 |
| 2010-01-01 | 32,600 |
| 2009-01-01 | 22,500 |

| Date of Loss | Paid & Outstanding Loss Amounts | ALAE |
| --- | --- | --- |
| 2013-07-21 | $2,000 | $0 |
| 2012-09-07 | 10,000 | 0 |
| 2011-04-01 | 100,000 | 20,000 |
| 2010-11-13 | 40,000 | 0 |
| 2010-02-14 | 70,000 | 0 |
| 2009-05-05 | 12,000 | 0 |

0.443 — Experience modification

Calculate the adjustment to reflect the ultimate level of loss.

## Solution

Since the policy being rated is effective 1/1/2014, we will use the policies (and claims from the policies) effective 1/1/2012, 1/1/2011, and 1/1/2010.

**CSLC:** 123,200 — `=SUM(D12:D14)`

Lookup CSLC of 123,200 to get:

| J | K |
| --- | --- |
| Z | 0.26 |
| EER | 0.876 |
| MSL | 122,250 |

Mod = Z * (AER - EER)/EER. Solve for AER = (Mod/Z)*EER + EER

**AER:** 2.369 — `=B25/K9*K10+K10`
