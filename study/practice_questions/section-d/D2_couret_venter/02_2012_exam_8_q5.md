# 2012 Exam 8 - Q5

**Points:** 3

## Question

The following data is used to price an excess of loss workers compensation policy:

- Data is available for the following injury types: fatal, permanent total injury (PT), major

permanent partial (Major), minor permanent partial (Minor), temporary total (TT), and medical-only (Med).

- A multi-dimensional credibility technique (predicted) was used to estimate the frequency for

class 5160.

### Part a (1.25 pts)

Determine whether multi-dimensional credibility relativities should be used to estimate the expected loss for fatal claims.

### Part b (1.75 pts)

Based on part (a) above, calculate the expected loss for the following excess workers compensation policy:

| B | C |

## Solution

### Part a

We want to use either the Hazard Group, credibility technique, or the raw data for fatal claims, based on which has the lowest SSE (compared to the holdout sample).

SSE_HG — 0.0250 — `=N29` — is lowest

The Hazard Group relativities result in the lowest Sum of Squared Errors for fatal claims, so they should be used for fatal claims instead of the multi-dimensional credibility relativities or the raw data relativities.

### Part b

There are a few issues with this problem. First, I assume that the payroll is all for class 5160, though WC policies can have multiple classes in practice. Second, we have no way of getting the expected ground-up loss for the risk that is particular to the class, so we'll have to use the frequency and severity information given by injury type. This means we can just estimate the expected excess losses directly instead of calculating an ELF for the class and then applying it to the expected ground-up loss for the risk. This would imply that the credibility-procedure can better estimate expected ground-up losses by injury type, though this was never the intention of the authors. Third, note that the LERs given are for deductibles, not limits, since you see 100% for the small injury types. As such, we have to use 1 - these LERs in our formula to get the excess ratios. For Med, TT, and Minor, the expected excess losses will be $0 since the XS ratios are 0%, so we can skip them to save time since we are going to estimate excess losses directly instead of obtaining new injury type weights to get a class ELF.

Med, TT, and Minor have $0 XS loss since 100% LERs.

Fourth issue: we are told that we need to use the credibility procedure frequency for PT, but we aren't given the predicted frequency for the class. Instead, we are given the predicted frequency for the quintile containing the class relative to the hazard group predicted frequency (i.e., w^est_quintile / w^est_h). So the best we can do is use this multiplied by the HG PT frequency to estimate the class PT frequency.

Fatal & Major use HG frequency. PT uses credibility procedure freq, so adjust HG freq for PT by 1.15 (quintile 4).

**HG TT counts:** 20 — `=B43*(F19/100)`
