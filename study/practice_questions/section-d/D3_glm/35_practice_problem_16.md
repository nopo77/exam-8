# Practice Problem 16

## Question

One measure used in diagnostic testing of GLMs is the deviance.

### Part a

Discuss the highest and lowest possible values of the scaled deviance.

### Part b

Discuss what conditions need to exist for deviance comparisons to be valid between 2 GLMs.

## Solution

### Part a

For a given dataset and error distribution, the lowest possible value of scaled deviance is 0, which would occur for a saturated model with one predictor variable for every observation in the dataset. The highest possible value of scaled deviance occurs when there are no predictor variables, in which case the scaled deviance represents the total deviance inherent in the data.

### Part b

All of the following conditions must exist for a valid comparison:

- The datasets used for both models must be identical (including the same number of records

used in each model).

- Both models use the same assumed distribution.
