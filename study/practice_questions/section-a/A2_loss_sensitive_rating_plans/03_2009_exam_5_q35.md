# 2009 Exam 5 - Q35

**Points:** 3.25

## Question

Given the following information:

| Frequency of Claims | Loss Amount per Claim |
| --- | --- |
| 45% | $22,000 |
| 20% | $35,000 |
| 15% | $150,000 |
| 15% | $250,000 |
| 5% | $1,000,000 |

| B | C |
| --- | --- |
| $24,793 | Full Coverage Premium |
| 59% | Expected Ground-up Loss Ratio |
| 10% | ALAE as a % of losses (assume the deductible does not apply to ALAE) |
| 4% | Incremental Fixed Expenses for processing a deductible as a % of losses in deductible layer |
| 1% | Load for uncollectible deductible payments as a % of losses in deductible layer |
| 8% | Profit |
| 5% | Additional Risk Load |
| 10% | Commission |
| 5% | Other Variable Expenses |
| $100,000 | Deductible |

Calculate the final premium for a policy with a $100,000 deductible.

## Solution

This is from exam 5, so the expense items given are slightly different, but the concepts are the same. We are given the severity distribution, and we can use it to first obtain the Loss Elimination Ratio and Excess Ratio.

LER — 0.409 — `=SUMPRODUCT(B7:B11,J7:J11)/SUMPRODUCT(B7:B11,C7:C11)` — For a deductible, so the LER numerator is losses below the deductible.

min(X,100k)

$22,000 — `=MIN(C7,B$22)` — XS Ratio — 0.591 — `=1-M5`

$35,000 — `=MIN(C8,B$22)`

$100,000 — `=MIN(C9,B$22)` — Now we can calculate expected losses above and below the deductible.

$100,000 — `=MIN(C10,B$22)`

$100,000 — `=MIN(C11,B$22)` — Expected Ground-up Loss — $14,627.87 — `=B13*B14`

**Expected XS Loss:** $8,645.31 — `=O11*M7`

**Expected Loss below D:** $5,982.56 — `=O11-O13`

ALAE is given as 10% of ground-up loss, since the deductible does not apply to ALAE.

**ALAE:** $1,462.79 — `=B15*O11`

The deductible processing expenses and load for uncollectible payments are given as percentages of losses below the deductible. The profit, commission, and other variable expenses will all vary with premium, and will go in the denominator of the pure premium method formula. The additional risk load is given as a percentage, but it is not specified as to what this is to be multiplied by, so I'll make an assumption and solve accordingly.

I assume the additional risk load is a percent of excess loss.

**Premium:** $14,077 — `=(O13*(1+B19)+O19+(B16+B17)*O15)/(1-SUM(B18,B20,B21))`
